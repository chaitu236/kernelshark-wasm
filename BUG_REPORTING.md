# Reporting bugs

For browser/WASM behavior, build or deployment failures, or issues with this
repository's patches, [open a GitHub issue](https://github.com/ni/kernelshark-wasm/issues/new).
Include steps to reproduce, expected and actual behavior, your browser and
operating system, and the build revision from **Help -> Sources** when available.

If the problem also occurs in an unmodified native upstream KernelShark build,
[report it to upstream](https://bugzilla.kernel.org/buglist.cgi?component=Trace-cmd%2FKernelshark&product=Tools&resolution=---).
Include the upstream version and reproduction steps.

If you are unsure where the bug belongs, open an issue here first.
